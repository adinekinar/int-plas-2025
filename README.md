# INT FPLAS Research Dataset – Flutter Programming Exercises & Documentation

## Overview

This repository contains supporting materials used in the research study titled  
**"A Guided Self-Study Platform of Integrating Documentation, Code, Visual Output, and Exercise for Flutter Cross-Platform Mobile Programming"**.

## Study Description

This study focuses on the development and evaluation of a self-learning environment for beginner-level Flutter programming. The materials in this repository were used during the experimental validation of the system, where students solved structured programming exercises related to Dart and Flutter.

## Repository Contents

- `material/` – Contains the full set of programming questions used during evaluation. These include:
  - Fill-in-the-blank style coding exercises
  - Conceptual and syntax-based questions

- `images/` – Screenshots showing expected outputs and UI behavior from selected problem instances

- `reference/` – Supplementary documentation provided to participants and Flutter/Dart documentation snippets

## Usage

1. Browse the `material/` folder to view the full set of problems.
2. Refer to `images/` to see output examples or UI states expected from each problem.
3. Use the `reference/` folder to understand the context and documentation provided to students during the study.
